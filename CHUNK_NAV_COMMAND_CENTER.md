# CHUNK_NAV_COMMAND_CENTER.md — Central Command Center (Bottom Sheet)

## Цель
Превратить текущую центральную кнопку нижней навигации в полноценный Command Center:
- быстрые действия
- статус пользователя
- расширенная навигация
- информация о приложении

Кнопка "Добавить запись" должна находиться ВНУТРИ Command Center.
Кнопка "Добавить запись" НЕ выносится в FAB и НЕ дублируется в контенте.

---

## 1. Общая концепция
Central Command Center:
- открывается по нажатию на центральную кнопку нижней навигации
- появляется снизу вверх (bottom sheet)
- закрывается:
  - по кнопке X
  - свайпом вниз
  - по клику на затемнённый backdrop
- backdrop затемняет фон на ~45%

---

## 2. Структура Command Center (сверху вниз)

### 2.1 Header
Содержимое:
- логотип приложения (использовать текущий)
- название: **FlareonFit**
- кнопка закрытия (X) справа

Стиль:
- центрированный логотип + название
- визуально отделён divider’ом

---

### 2.2 User Status Block
Показывает текущий статус пользователя (данные уже есть в API):

- 🔥 Серия: `X дней`
- ⚡ XP за неделю: `N`

Поведение:
- данные берутся из `/social/me`
- блок кликабелен → переход на `/profile` (или будущий экран достижений)

---

### 2.3 Quick Actions (ВАЖНО)
Основной интерактивный блок.

Кнопки (вертикальный список или grid 2×2):

1. ➕ **Добавить запись**
   - primary action
   - ведёт на `/entry/new`
   - после клика Command Center закрывается

2. 📅 **Выбрать дату**
   - открывает date picker
   - после выбора:
     - переход на `/today?date=YYYY-MM-DD`
     - Command Center закрывается

3. ⭐ **Избранные продукты**
   - переход на `/products?tab=favorites`

(если чего-то ещё нет — заглушка допустима)

---

### 2.4 Navigation (Secondary)
Навигация по разделам приложения (НЕ дублирует нижнюю панель 1:1, а расширяет её):

- 🏆 Лига → `/league`
- 👥 Друзья → `/friends`
- 📰 Лента → `/feed`
- 🛒 Продукты → `/products`
- 👤 Профиль → `/profile`

Стиль:
- компактный список
- иконка + текст
- без акцента (не primary)

---

### 2.5 Footer
Информационный блок:
- версия приложения (например `v1.0.0`)
- опционально: кнопка “О приложении” (пока можно без действия)

---

## 3. UX и анимации
- Анимация открытия: `ease-out`, 250–300ms
- Небольшой overshoot (если просто — без overshoot)
- Поддержка свайпа вниз:
  - если dragY > 80px → закрыть
- Использовать Telegram.WebApp.HapticFeedback:
  - light impact при открытии
  - light impact при нажатии "Добавить запись"

---

## 4. Интеграция с текущей навигацией
- Центральная кнопка нижней панели:
  - открывает Command Center
  - НЕ является переходом на маршрут
- Нижняя навигация остаётся:
  - Today
  - League
  - Feed
  - Friends
  - Profile

---

## 5. Acceptance Criteria
1. Центральная кнопка открывает Command Center.
2. Внутри есть кнопка "Добавить запись", ведущая на `/entry/new`.
3. Есть блок статуса пользователя (серия + XP).
4. Command Center закрывается по:
   - X
   - backdrop
   - свайпу вниз
5. Ничего не дублируется и не ломает существующую навигацию.
6. Работает в Telegram Mini App.
