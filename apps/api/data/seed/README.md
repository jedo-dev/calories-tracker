# Seed Recipes

Скрипт для создания ~680 реалистичных русскоязычных рецептов в базе данных.

## Запуск

```bash
cd apps/api
npm run seed:recipes
```

## Что делает скрипт

1. Находит или создаёт тестового пользователя `megamanok99@gmail.com`
2. Загружает все продукты из БД в кеш
3. Создаёт недостающие продукты-ингредиенты с примерной КБЖУ
4. Создаёт/обновляет рецепты через upsert по `userId + nameNormalized`
5. Рассчитывает КБЖУ из ингредиентов (режим `ingredients`)
6. Проверяет физическую корректность данных (сумма Б+Ж+У ≤ 100г/100г)

## Идемпотентность

Повторный запуск не создаёт дубликаты — рецепты обновляются по `userId + nameNormalized`.

## Категории рецептов

- Завтраки (каши, омлеты, сырники, блины, бутерброды)
- Супы (борщ, щи, крем-супы, уха, окрошка)
- Мясо и птица (котлеты, плов, шашлык, жаркое)
- Рыба (запечённая, на пару, котлеты)
- Паста и макароны (карбонара, болоньезе, лазанья)
- Гарниры (пюре, гречка, рис)
- Салаты (Цезарь, Греческий, Оливье, винегрет)
- Лёгкие ужины (овощи, запеканки)
- Перекусы (смузи, йогурт, орехи)
- ПП-блюда (низкокалорийные)
- Блюда для набора массы
- Домашняя выпечка (пирожки, пицца)
- Азиатская кухня

## Структура данных

Файлы с рецептами:
- `data/seed/recipes-data.ts` — основные категории (завтраки, супы) + экспорт всех рецептов
- `data/seed/recipes-more.ts` — мясо, рыба, паста, гарниры, салаты, перекусы
- `data/seed/recipes-extra.ts` — вариации овсянки, омлетов, творога, салатов, супов, котлет
- `data/seed/recipes-final.ts` — завтраки, курица, говядина, свинина, салаты, перекусы, напитки
- `data/seed/recipes-mega.ts` — каши на разном молоке, бутерброды, комбинации мяса/рыбы с гарнирами
- `data/seed/recipes-ultra.ts` — каши, омлеты, сырники, блины, котлеты, запеканки
- `data/seed/recipes-last.ts` — финальные вариации до ~680 рецептов

## Проверки качества

Скрипт автоматически проверяет:
- Сумма Б+Ж+У на 100г ≤ 100г (физически невозможно больше)
- Калории примерно соответствуют макросам (допуск 40%)
- Все ингредиенты существуют в базе продуктов

## Переменные окружения

- `MONGO_URI` — строка подключения к MongoDB (из `.env`)
