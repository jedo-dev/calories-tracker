Лоадеры FlareonFit

Чистый SVG + SMIL, без JS и без зависимостей. Палитра сайта: #0D2231 / #F58A3C / #4CB558 / #FDECDC.

Лис

Основной лоадер: прыгает, шевелит ушами и моргает, вокруг бежит зелёная дуга. Для полноэкранной загрузки и сплэша.

fox-loader.svg

Гантель

Гантель крутится с лёгким «замахом», рядом следы движения. Для загрузки тренировок.

dumbbell-loader.svg

Кольцо

Нейтральный indeterminate-спиннер с градиентом бренда. Для мелких мест: кнопки, списки, pull-to-refresh.

ring-loader.svg

Блины

Три блина от штанги прыгают волной. Для инлайновых подгрузок и «идёт сохранение».

dots-loader.svg

Как подключить — файл работает и как картинка, и инлайном (инлайн предпочтительнее: можно менять цвета через CSS):

<img src="/loaders/fox-loader.svg" width="72" height="72" alt="Загрузка">

Анимация встроена в сам SVG (SMIL), поэтому работает в Chrome, Safari, Firefox и в WebView мобильных приложений. Фон у всех файлов прозрачный, размер задаётся через width/height — векторы не мылятся.
