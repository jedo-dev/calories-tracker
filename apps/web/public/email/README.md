# Картинки для писем

Раздаются статикой web-приложения: `{APP_URL}/email/<файл>` — в письмах
только абсолютные https-ссылки (вложения = «письмо с вложением» в Gmail).

Положить сюда (имена важны, их ждёт шаблон `apps/api/src/mail/templates/`):

- `hero.png` — маскот-лис с гантелей, 1200×560 (в письме показывается 600×280, @2x для retina)
- `meal_128.png` — иконка тарелки с приборами, 128×128
- `workout_128.png` — иконка гантели, 128×128
- `xp-bolt_128.png` — иконка молнии XP, 128×128
