# FlareonFit — Промт Для Генерации Изображений

## О Проекте

**FlareonFit** — это мобильное Telegram Mini App для трекинга калорий, питания и тренировок. Приложение работает в тёмной теме с акцентами зелёного (#53D46B) на тёмно-синем фоне (#0D2231). Стиль — современный, минималистичный, с мягкими скруглениями и иконками в стиле line art / flat design.

### Цветовая Палитра

| Роль | Цвет | HEX |
|------|------|-----|
| Фон основной | Тёмно-синий | `#0D2231` |
| Поверхность | Сине-зелёный | `#1A3A4A` |
| Акцент / Primary | Зелёный | `#53D46B` |
| Текст основной | Белый | `#FFFFFF` |
| Текст вторичный | Серо-голубой | `#94A3B8` |
| Опасность | Красный | `#E53E3E` |
| Успех | Зелёный | `#53D46B` |
| Границы | Сине-серый | `#2A4A5A` |

### Стиль

- Минимализм, чистые линии
- Скруглённые углы (8-12px)
- Мягкие тени
- Иконки: line art, 2px stroke, rounded caps
- Иллюстрации: flat design, мягкие градиенты, без лишних деталей
- Фон иллюстраций: тёмно-синий (#0D2231) или прозрачный
