# FlareonFit — Master Image Generation Prompt

Hand this whole file to an image-generation AI. It contains (1) a GLOBAL STYLE
block that must be applied to EVERY image, and (2) a numbered list of all assets
with an individual prompt + target filename for each. Generate one image per item.
All prompts are in English for best model adherence.

---

## GLOBAL STYLE (apply to every single image — append to each item prompt)

Visual identity for "FlareonFit", a calorie-tracking & fitness mobile app.

**STYLE:** modern, minimal, flat design / line art. Clean confident shapes, soft rounded corners, low detail, soft minimal shadows, high contrast.

**PALETTE (use exactly these):**
- Background: dark navy blue `#0D2231` (or transparent where noted)
- Surface: teal-blue `#1A3A4A`
- Primary / accent: vibrant green `#53D46B`
- Primary text: white `#FFFFFF`
- Secondary: gray-blue `#94A3B8`
- Danger: red `#E53E3E`
- Gold (awards): `#FFD700`
- Water: blue `#4A9EFF`

**LINE ICONS:** 2px stroke, rounded caps, centered, generous padding.

**MASCOT:** a cute friendly orange fox (Flareon-style) with green `#53D46B` sportswear accents and a fluffy white-tipped tail; keep the SAME fox design across all mascot images for consistency.

**HARD RULES:** NO text, letters, words, numbers (unless explicitly stated), watermarks, signatures, or logos. Centered composition. One subject per image.
