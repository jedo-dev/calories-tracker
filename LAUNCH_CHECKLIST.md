# Чеклист к публикации в прод

Актуален на 2026-08-15. Черта отсечения: без пунктов «🔴 Блокер» запускаться
нельзя, «🟡 Важно» — можно запуститься и доделать в первые недели,
«🟢 Потом» — после запуска по данным аналитики.

## 🔴 Блокеры (данные и безопасность)

- [ ] **Бэкапы MongoDB.** Cron с `mongodump` → MinIO/S3, ротация 14 дней,
      один проверенный восстановленный дамп. Сейчас сбой диска = потеря всех
      дневников.
- [ ] **Rate limiting.** `@nestjs/throttler`: жёсткий лимит на `/auth/*`
      (брутфорс) и `/ai/*` (платные токены), мягкий на остальное API.
- [ ] **Убрать дефолтные секреты из compose.** `S3_ACCESS_KEY:-minioadmin` —
      если секрет в GitHub не задан, MinIO поднимется с паролем по умолчанию.
      Деплой должен падать явно.
- [ ] **tsc в CI перед деплоем.** Шаг `tsc --noEmit` (api + web) в
      `main.yml` до docker build — сейчас сломанный тип уезжает в прод.
- [x] **Юридика.** Политика конфиденциальности (`/privacy`, согласие при
      регистрации) + полное удаление аккаунта (профиль → «Удаление аккаунта»).
      ⚠️ Текст политики — черновик: перед публикацией показать юристу и
      вписать реквизиты оператора данных.
- [x] **Подтверждение почты.** Письмо с ссылкой активации при регистрации
      (nodemailer, env `SMTP_*`/`APP_URL`), мягкий баннер в профиле,
      переотправка. Без SMTP-настроек почта считается подтверждённой.
      ⚠️ Добавить SMTP-секреты в GitHub перед деплоем.

## 🟢 Потом (по данным аналитики)

- [ ] **Гифки/анимации упражнений для тренировок.** Скрипты
      `seed:exercise-anims` / `seed:wger-images` уже есть — прогнать и
      проверить покрытие библиотеки упражнений; дыры добить генерацией.
- [ ] **Очереди (BullMQ + Redis) — только при реальной нагрузке.**
      Сейчас криты нет: AI-распознавание — один внешний HTTP-вызов,
      пуши — крон, аналитика — insertMany. Очереди понадобятся, когда:
      рассылка пушей > ~1000 подписок за тик, придут вебхуки платёжки
      (ретраи!), или появится тяжёлая генерация (отчёты/экспорт).
      До этого Redis в стеке — лишняя движущаяся деталь.
- [ ] **PWA-офлайн.** Кэш статики + офлайн-очередь записей еды
      (записать обед без сети → синк при появлении). Заметный плюс
      для трекера, но требует аккуратного конфликт-резолва.
- [ ] **Capacitor вместо TWA**: фоновые шаги (аппаратный счётчик),
      HealthKit / Health Connect, нативные пуши на iOS без PWA-установки.
- [ ] **Онбординг-волна 2**: отложенная регистрация (демо до signup),
      персональный первый экран после регистрации.
- [ ] **Восстановление пароля** (сброс по email — инфраструктура почты
      уже есть в `src/mail`).
