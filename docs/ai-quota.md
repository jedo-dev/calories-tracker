# Лимиты AI-распознаваний еды по фото

## Как работает сейчас

- Каждому пользователю даётся **10 бесплатных распознаваний в месяц** (настраивается env `AI_MONTHLY_LIMIT`, дефолт 10). Счётчик сбрасывается со сменой календарного месяца.
- **Бонусные токены** (с промокодов) не сгорают и тратятся после исчерпания бесплатного лимита.
- Списание происходит перед запросом к AI-провайдеру; при ошибке провайдера попытка возвращается.
- При исчерпании лимита `POST /ai/food-photo` отвечает `403 AI_LIMIT_EXHAUSTED`, кнопка на фронте блокируется и ведёт на `/ai-limits`.

### Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/ai/quota` | `{ monthlyLimit, usedThisMonth, bonusTokens, remaining }` |
| `POST` | `/ai/promo` | `{ code }` → `{ addedTokens, quota }` |
| `POST` | `/ai/food-photo` | распознавание (списывает 1) |

### Коллекции Mongo

- `aiquotas` — `{ userId, month: 'YYYY-MM', used }` (unique index userId+month)
- `aibalances` — `{ userId, bonusTokens }`
- `aipromocodes` — промокоды

### Как создать промокод

Админки нет — промокоды создаются вручную в Mongo:

```js
db.aipromocodes.insertOne({
  code: "FLAREON10",        // хранить в ВЕРХНЕМ регистре
  tokens: 10,                // сколько распознаваний даёт
  maxUses: 100,              // 0 = без ограничения активаций
  usedBy: [],
  expiresAt: ISODate("2026-12-31"), // опционально
  createdAt: new Date(),
  updatedAt: new Date(),
})
```

Один пользователь может активировать каждый код только один раз.
